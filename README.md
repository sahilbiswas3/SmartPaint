# Smart Painting - Interior Services Website

## Overview
This is a responsive website for a local interior painting and renovation business based in Kolkata. The website showcases the company's services, portfolio, and contact information.

## Features
- Responsive design that works on mobile, tablet, and desktop devices
- Modern UI with smooth animations and transitions
- Service showcase with icons and descriptions
- Filterable portfolio gallery
- Contact form for customer inquiries
- Mobile-friendly navigation

## Pages
1. **Home Page (index.html)** - Main landing page with all sections
2. **Portfolio Page (portfolio.html)** - Extended gallery of completed projects

## Sections
- Hero/Banner with call-to-action buttons
- About Us with company information
- Services with categorized offerings
- Portfolio with filterable project gallery
- Work Process timeline
- Contact section with form and details
- Footer with navigation and social links

## Technologies Used
- HTML5
- CSS3 (with Flexbox and Grid layouts)
- JavaScript (Vanilla JS for interactivity)
- Google Fonts (Poppins and Open Sans)
- Font Awesome icons

## Color Scheme
- Primary Color (Ocean Blue): #0077B6
- Secondary Color (Cyan): #00B4D8
- Accent Color (Soft Pink): #FFB6B9
- Dark Color: #333333
- Light Color: #f8f9fa

## How to Use
1. Open `index.html` in a web browser to view the website
2. Navigate through sections using the top navigation menu
3. Click on portfolio filters to view different categories of work
4. Fill out the contact form to send inquiries
